# LoCoCLIP

**LoCoCLIP: Integrating Local and Contextual Evidence for Training-Free Multi-Label Image Recognition**

This repository accompanies our paper on training-free multi-label image recognition with frozen vision-language models.

## Code Availability

The source code is not publicly available yet. It will be released in this repository after the paper is accepted for publication.

Implementation details and instructions for reproducing the results will be provided with the code release.
